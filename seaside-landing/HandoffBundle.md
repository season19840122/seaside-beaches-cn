# HandoffBundle

> 交付物：`prototype-浅水区-海图标-四海色.html`（单文件，可直接交付开发）
> 设计方向：ConceptRoutes 混合配方「A 骨 + B 标 + C 色」
> 页面目标：让访客 30 秒内定位「我要去的省份/海域 → 有哪些能下水的浴场」，并分清天然 / 人工受限 / 禁止下水
> 日期：2026-09-19

### 1.6 卡片样式

- 面 `#FFFFFF` / 边 `1px solid #DDE6E3` / 圆角 `10px` / 内边距 `16px 24px 24px`
- **签名元素 · 泳道线**：卡片顶部一条 6px 刻度轨道，填充宽度 = 该省级行政区收录浴场数 ÷ 全省最大值（广东 24 处为 100% 基准）；线端一个 9px 浮标圆点居中于刻度值处
- 刻度轨道带 14px 间隔的发丝刻度线，呼应「海图」标注语言
- hover：边框转深靛青、`translateY(-2px)`、阴影 `md`、浮标由橙转深靛青、浴场标签边框加深

## 二、ComponentSpec

> 组件总数：10 | 状态矩阵见 QAReport 第四节

### 2.1 `SeaRailItem` — 海域标尺项
- **用途**：桌面端海域导航，兼作滚动监听指示器
- **变体**：default / current（`aria-current="true"`）
- **状态**：default 边框透明、文字 `#4E6165`；hover 底 `#FFFFFF` + 边框 `#C6D4D0` + 文字转 `#16282C`；current 左边框 2px `--sea-ink` + 底白 + 文字 `#16282C`；active 底 `--deep-tint` + 边框转 `--deep`；focus 全局 ring
- **尺寸**：宽 212px；内边距 12px 16px；左缩进边框 2px

### 2.2 `SeaTab` — 移动海域标签
- **用途**：<1024px 的海域快速跳转，吸顶
- **变体**：default / current
- **状态**：全套（hover 边框加深、active `scale(.97)` + 底色、focus 全局 ring）
- **尺寸**：高 **44px**（触控达标）；内边距 0 16px；含 8px 色块 + 文字 + 计数

### 2.3 `ProvinceCard` — 省份卡片
- **用途**：承载一个省级行政区的全部城市与浴场
- **变体**：普通 / 含「跨海域」标记 / 含「仅人工沙滩」标记 / 含「含禁止下水」标记
- **状态**：default / hover（本卡片非直接可点，hover 为整体强调）
- **尺寸**：双列时最小约 380px；内边距 16px 24px 24px；顶部泳道线区 16px

### 2.4 `LaneGauge` — 泳道线（签名组件）
- **用途**：可视化该省收录浴场数量，全网最强识别元素
- **结构**：`.lane`（定位容器）→ `.lane__gauge`（刻度区间）→ `.lane__fill` + `.lane__buoy`
- **关键实现**：`--lane` 百分比必须相对 `.lane__gauge` 解析，**不能**相对 `.lane`——后者因两侧各内缩 24px 会导致比例失真且满格时浮标越界
- **状态**：默认静止；卡片 hover 时浮标由 `#E8502F` 转 `#0B4F5C`

### 2.5 `CityItem` — 城市条目
- **用途**：一个城市及其浴场清单
- **变体**：按 `data-status` 三态着色说明文字
- **状态**：default / 随卡片 hover 边框变化
- **尺寸**：上分隔虚线 1px；内边距上 16px

### 2.6 `StatusBadge` — 下海资格徽标
- **用途**：标记天然可下水 / 人工受限 / 禁止下水
- **变体**：`--swim` / `--caution` / `--nogo`
- **设计要点**：**色彩 + 形状双编码**——实心圆点 = 可下水，半填充圆点 = 人工受限，空心加斜杠 = 禁止下水。确保色觉障碍用户也能区分
- **尺寸**：内边距 4px 8px；圆角 3px；圆点 10px；文字 12.5px

### 2.7 `BeachTag` — 浴场标签
- **用途**：单个浴场名
- **变体**：default / `is-hit`（搜索命中）
- **状态**：default 底 `#F4F7F5` + 边 `#DDE6E3`；命中底色 `#FFF1EC` + 边 `#E8502F`
- **尺寸**：内边距 4px 8px；圆角 3px；文字 13.5px；**最小触控/悬停高度 27px**（非交互元素，无需 44px）

### 2.8 `FilterChip` — 状态筛选
- **用途**：按下海资格筛选
- **变体**：`aria-pressed="false/true"`，可与搜索叠加（多选）
- **状态**：全套；选中态底色 `--deep` + 白字 + 图形点转白
- **尺寸**：桌面高 34px；移动 **44px**；内边距 0 12px

### 2.9 `NoticePanel` — 需注意面板
- **用途**：集中说明易混淆的人工/受限水域
- **结构**：顶部 3px `--caution` 强调边 + 眉题 + 标题 + 说明 + 2 列条目网格
- **尺寸**：圆角 16px；内边距 32px；条目内边距 16px

### 2.10 `CollapsibleFootnote` — 折叠说明
- **用途**：放置「有海岸线但不适合下海」的次要信息，用折叠降低视觉权重
- **状态**：`data-open="true/false"` + `aria-expanded` 同步；用 `grid-template-rows:0fr→1fr` 实现无需测高的平滑展开
- **尺寸**：按钮内边距 16px 24px；移动端实测高 80px

## 三、开发者说明

### 3.1 文件与依赖
- 单文件 `prototype-浅水区-海图标-四海色.html`，无构建步骤、无 JS 框架依赖
- 唯一外部依赖：Google Fonts（**异步加载**，见下）
- 可直接部署到任意静态托管

### 3.2 字体加载（重要）
```html
<link rel="stylesheet" media="print" onload="this.media='all'" href="...">
<noscript><link rel="stylesheet" href="..."></noscript>
```
**不要改回同步 `<link rel="stylesheet">`**。Google Fonts 在部分网络环境下会长时间挂起，同步加载会阻塞首屏渲染造成白屏。当前实现实测**首屏 59ms 即可见**（拦截字体请求的条件下），字体到位后自动升级。CSS 中已配置气质接近的系统字体降级链。

### 3.3 数据结构约定
- 每个省份卡片上有 `data-search`：拼接该省所有城市名与浴场名的可搜索文本
- 每个城市条目有 `data-status="swim|caution|nogo"`（驱动状态筛选）与自己的 `data-search`
- 搜索的两级行为：
  - 命中**城市/浴场**（如「付家庄」）→ 只保留命中的城市
  - 只在**省级**命中（如「辽宁」）→ 保留该省全部城市
  - 该逻辑由 `showWholeProvince = cardHit && !anyCityHit` 一行控制，改动时注意保持
- `.lane` 的 `--lane` 为内联百分比，基准值 = 24（广东）。新增省份时需同步该基准

### 3.4 内容维护提示
- 页面数据全部内联在 HTML 中，无 JSON 数据源。若要内容与视图分离，建议抽出 `SEA_DATA` 结构后由模板渲染，同时保留 `data-*` 属性命名不变（JS 依赖这些钩子）
- 页脚统计「14 个省级行政区 · 56 座城市与区 · 140 处浴场」需与内容同步；**140 = 各省泳道线计数之和**，是唯一权威值
- 中国台湾 / 中国香港 / 中国澳门 的称谓必须保持规范写法，不可简写

### 3.5 无障碍维护要点
- **海域色双档制**：任何新增的、需要承载文字的海域色用法，必须走 `--sea-ink`
- **浮标橙 `#E8502F` 对比度仅 3.45:1**：只允许用于 ≥24px 大字、focus ring、图形。新增承载正文的橙色按钮必须改用深靛青底白字
- 状态徽标必须保持色彩 + 形状双编码，不可只靠颜色
- 移动端新增可点元素须 `min-height:44px`

### 3.6 浏览器兼容
- 使用 `text-wrap: balance`（Chrome 114+ / Safari 17.4+），不支持时优雅退化为普通换行，不影响可读性
- `backdrop-filter` 已带 `-webkit-` 前缀
- `grid-template-rows: 0fr → 1fr` 折叠动画在全部现代浏览器可用
- 已在 Chrome 实测 320 / 360 / 375 / 390 / 414 / 430 / 600 / 768 / 834 / 1024 / 1280 / 1440 / 1920 共 13 档宽度，无横向溢出
