# 全国海滨浴场可下水查询 · 落地页

一份按「能不能真的下海游泳」为标准的全国沿海城市浴场索引落地页。

> 有海岸线的城市很多，能**真的下海游泳**的没那么多。

## 在线访问

- 落地页：<https://season19840122.github.io/seaside-beaches-cn/>

## 这是什么

原始内容是覆盖 18 个省级行政区（含中国台湾、中国香港、中国澳门）的海滨浴场清单，另含「人工／受限浴场」与「有海岸线但不适合下海」两类补充信息。

这三类信息对访客的价值完全不同，因此页面用**视觉分层**而不是平铺呈现，并按四大海域（渤海 / 黄海 / 东海 / 南海）分区，配合「下海资格」三档状态标记：

| 状态 | 含义 |
|---|---|
| 天然可下水 | 有正式海滨浴场，可正常游泳 |
| 人工／受限 | 人工沙滩或受管制，需注意开放范围 |
| 禁止下水 | 有海岸线但无合规浴场，不建议下海 |

## 设计方向

**「A 骨 + B 标 + C 色」** —— 浅水区骨架 + 海图标注语言 + 四海语义色。

- **骨架**：泳池的几何秩序（泳道线、水深标尺、浮标圆点）。浅青灰白底，深靛青主色，浮标橙强调。
- **标注**：航海图的刻度与等宽字体，承担数据层的精确感。
- **语义色**：渤海灰绿 / 黄海沙黄 / 东海青蓝 / 南海深碧，四个真实水色即导航系统。

**签名元素是泳道线**：每张省份卡片顶部一条刻度轨道，填充长度对应该省收录的浴场密度，线端的橙色浮标点既是装饰也是数值标注。

页面为**单文件自包含** HTML，无构建步骤、无本地静态资源依赖（仅异步加载 Google Fonts，且带完整回退栈）。
